# ③ 사용자 시나리오

## 3.1 게시판 탐색 및 확인

사용자가 게시판 목록에 진입하여 게시글 목록을 조회한다. 관심 있는 게시글이 있다면 게시글 목록에서 해당 게시글을 선택하여 상세 화면으로 이동한다. 상세 화면에서는 제목, 작성자, 본문, 작성 시간, 공감 수, 댓글 수, 댓글 목록을 확인할 수 있다.

## 3.2 게시글 작성

사용자가 게시판 목록 하단의 ‘글 쓰기’ 버튼을 탭하고 글 쓰기 화면이 열리면 제목과 본문을 입력한다. 익명 여부를 선택하고 ‘완료’ 버튼을 탭하여 게시글을 등록한다. 등록이 완료되면 게시판 목록으로 돌아가며, 새 게시글이 상단에 표시된다.

## 3.3 댓글 및 대댓글 작성

게시글 상세 화면에서 하단 댓글 입력창에 텍스트를 입력하고 익명 여부를 선택한 후 전송 버튼을 탭하여 댓글을 등록한다. 기존 댓글에 대댓글을 작성할 수 있으며, 이는 들여쓰기로 구분된다.

## 3.4 게시글 공감

게시글 상세 화면에서 공감 버튼을 누를 수 있으며, 해당 글자 옆의 숫자로 공감 개수를 알 수 있다.

## 4.5 도메인 관계

### 4.5.1 User ↔ Post

- `User` 한 명은 여러 개의 `Post`를 작성할 수 있다.
- `Post` 하나는 한 명의 `User`에 의해 작성된다.

### 4.5.2 Post ↔ Comment

- `Post` 하나는 여러 개의 `Comment`를 가질 수 있다.
- `Comment` 하나는 한 개의 `Post`에 속한다.

### 4.5.3 User ↔ Comment

- `User` 한 명은 여러 개의 `Comment`를 작성할 수 있다.
- `Comment` 하나는 한 명의 `User`에 의해 작성된다.

### 4.5.4 Comment ↔ Comment

- `Comment` 하나는 여러 개의 자식 `Comment`를 가질 수 있다.
- `Comment` 하나는 선택적으로 하나의 부모 `Comment`에 속한다.

### 4.5.5 User ↔ Post ↔ PostReaction

- `PostReaction` 하나는 한 명의 `User`가 하나의 `Post`에 남긴 공감 기록이다.
- `User` 한 명은 여러 `PostReaction`을 남길 수 있다.
- `Post`는 여러 `PostReaction`을 받을 수 있다.

# ⑤ 화면별 기능 요구사항

## 5.1 자유게시판 목록

### 5.1.1 게시글 목록 조회

자유게시판 목록 화면은 게시글 목록을 표시한다. 각 게시글 항목에는 제목, 작성자, 생성 시각, 조회 수 정보를 표시한다.

### 5.1.2 게시글 항목 선택

게시글 항목을 선택하면 게시글 상세 페이지로 이동한다.

### 5.1.3 HOT 인기 게시글

HOT 인기 게시글은 일반 게시글 목록의 상단에 표시되며, 강조 색상으로 구분한다.

### 5.1.4 글쓰기 이동

글 쓰기 버튼을 누르면 게시글 작성 화면으로 이동한다.

## 5.2 게시글 상세

### 5.2.1 게시글 상세 조회

게시글 상세 조회 화면에서는 제목, 본문, 작성자, 공감 수, 생성 시각, 게시판 종류를 표시한다.

### 5.2.2 게시글 댓글 조회

게시글 댓글은 부모 댓글이 없다면 일반 댓글, 있다면 대댓글로 구분하여 표시한다. 또한, 작성자, 댓글 내용, 생성 시각을 표시한다.

### 5.2.3 게시글 댓글 작성

사용자가 댓글 입력창에 텍스트를 입력하고 익명 여부를 선택한 후 전송 버튼을 누르면 댓글이 등록된다. 또한, 기존 댓글을 선택한 뒤 댓글을 작성하면 선택한 댓글의 대댓글이 등록된다.

### 5.2.4 게시글 공감

공감 버튼을 누르면 공감이 등록되며, 공감 수가 1 증가한다. 공감 버튼을 한 번 더 누르면, 공감이 취소되며 공감 수가 1 감소한다.

## 5.3 게시글 작성

### 5.3.1 제목/본문 입력

제목은 최대 50자까지 입력할 수 있으며, 본문 없이 제목으로만 게시글을 등록할 수 있다.

### 5.3.2 익명 선택

게시글의 작성자 정보가 익명으로 표시될지 아닐지 선택할 수 있으며, 익명을 선택한다면 ‘익명’으로 표현되고 익명을 선택하지 않는다면 닉네임으로 표현된다.

### 5.3.3 이용규칙 확인

본문 작성 밑 ‘커뮤니티 이용규칙 전체 보기’ 버튼을 누르면 이용 규칙을 확인할 수 있다. 또한, 해당 버튼 하단에 커뮤니티 규칙 요약이 표시된다.

### 5.3.4 게시글 등록

우측 상단의 ‘완료’ 버튼을 누르면 게시글이 등록되며 자유게시판 목록 화면으로 이동한다. 또한, 등록된 새 게시글이 일반 게시글 목록 상단에 표시된다.

# ⑥ 검증 및 기능 규칙

## 6.1 게시글 작성 규칙

- 제목은 최대 50자까지 작성 가능하다.
- 본문 없이 제목만으로 게시글을 등록할 수 있다.

## 6.2 댓글 및 대댓글 작성 규칙

- 일반 댓글과 대댓글은 부모 댓글의 존재 여부로 구분한다.

## 6.3 게시글 공감 규칙

- 한 명의 사용자는 하나의 게시글에 한 번만 공감할 수 있다.
- 이미 공감한 사용자가 다시 공감 버튼을 누르면 공감은 취소된다.

## 6.4 익명 작성 규칙

- 익명을 선택했을 때는 작성자 이름이 ‘익명’으로 표시되며, 선택하지 않았다면 작성자의 닉네임으로 표시된다.
- 익명 여부는 게시글 작성과 댓글 작성에 모두 선택할 수 있다.

# ⑦ 예외 및 오류 처리 기준

## 7.1 입력값 오류

제목 길이가 50자를 넘긴다면 50자를 초과하는 문자는 입력되지 않는다.

## 7.2 존재하지 않는 게시글 또는 댓글

목록이나 링크를 통해 이미 삭제되었거나 존재하지 않는 게시글 또는 댓글을 연다면 페이지를 조회할 수 없다는 안내가 적힌 화면을 표시한다.

# ⑧ 비기능 요구사항

## 8.1 정합성

- 4.6 도메인 제약 조건의 중복 공감 제약을 유지한다.

## 8.2 보안

- 인증되지 않은 사용자는 글 작성, 공감, 댓글 작성이 불가능하다.
- 작성자 정보 중 내부 식별자는 사용자에게 공개하면 안 된다.
- 다른 사용자가 다른 사용자의 작성물을 수정하거나 삭제할 수 없다.
